# Gra Mobilna "DeptCollector" (Android) 
Stworzenie od podstaw mobilnej gry zręcznościowej inspirowanej mechaniką automatów losowych (jednoręki bandyta) z wdrożonym systemem zarządzania saldem i mikrotransakcjami. Implementacja dynamicznej rozgrywki, obsługi zdarzeń dotykowych oraz mechanik stanów gry. 

(Technologie: Kotlin, Android SDK, XML).
