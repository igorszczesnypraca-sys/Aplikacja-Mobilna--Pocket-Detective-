# Aplikacja Mobilna "Pocket Detective"
aprojektowanie i stworzenie natywnej, interaktywnej gry detektywistycznej zawierającej wbudowane minigry (np. układanki logiczne) oraz zróżnicowane ekrany (galeria, bank, notatnik). Implementacja dynamicznego interfejsu, obsługi zdarzeń dotykowych oraz trwałego zapisu postępów gracza..  (Technologie: Kotlin, Android SDK, XML).
